# HR Management & Payroll System

## Project Overview
A web-based HR Management and Payroll System built for ISE Degree Project.

## Features (Planned)
- Employee Management
- Attendance Tracking
- Leave Management
- Payroll Generation
- Admin Dashboard & Reports

## Tech Stack
- **Backend:** Laravel (PHP)
- **Database:** MySQL
- **Frontend:** Blade, Bootstrap, JavaScript
- **Reports:** Chart.js, DOMPDF
